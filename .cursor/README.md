# Cursor MCP

Edit **`mcp.json`** in this folder to point Cursor at this project.

- Prefer opening **`misunderstood_mcp`** as the workspace root so `"cwd": "."` works.
- If the workspace is a **parent** folder, use **absolute** paths to `node_modules/tsx/dist/cli.mjs` and `mcp-server-socket.ts` (see repo `README.md`).
